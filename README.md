# 🏦 Bank Management System

A professional desktop banking application engineered using **Qt (C++)**, designed to simulate core banking operations with a clean, responsive, and intuitive user interface. The project demonstrates practical software engineering principles, object-oriented programming, and desktop application development by providing a structured environment for managing customer accounts and everyday banking activities.

Built as an academic and portfolio project, the application focuses on writing clean, maintainable code while delivering a user experience similar to a real-world banking system.
